# somnium

Site da Somnium: sites e sistemas para pequenos negócios.

Site estático (HTML, CSS e JavaScript simples), sem framework e sem etapa de
build. Publicado no GitHub Pages em
<https://lucasoliveira0jcc-ux.github.io/somnium/>.

## Estrutura

```
index.html   página inicial
config.js    contato, cidade e caminhos do portfólio (edite aqui)
css/         estilos (cores e fontes em css/tokens.css)
js/          scripts da página
img/         imagens e favicon
demos/       demonstrações do portfólio (veja demos/README.md)
```

## Rodar localmente

Abra o `index.html` direto no navegador, ou sirva a pasta com um servidor
simples:

```bash
python -m http.server 8000
```

e acesse <http://localhost:8000>.
