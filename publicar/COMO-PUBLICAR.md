# Publicar no GitHub Pages

1. Crie um repositório público no GitHub (ex.: `somnium`).
2. Envie todo o conteúdo desta pasta `publicar/` para a raiz do repositório: `index.html` e a pasta `logo/`.
3. No repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, pasta `/ (root)` → **Save**.
4. Em 1 ou 2 minutos o site fica em `https://SEU-USUARIO.github.io/somnium/`.

## Depois de publicar
- Me passe o endereço final: a imagem de compartilhamento do WhatsApp precisa do endereço completo (`og:image`) para aparecer.
- Domínio próprio (opcional, depois): em **Settings → Pages → Custom domain**, e um registro CNAME no seu provedor de domínio.
